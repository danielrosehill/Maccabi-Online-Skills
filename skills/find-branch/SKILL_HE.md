# איתור סניף / מרכז רפואי

מדריך השירותים הציבורי; אין צורך בסשן מחובר. תבנית כתובת:

```
https://serguide.maccabi4u.co.il/heb/medicalcentres/medicalcentressearchresults/?City={city_code}&PageNumber={page}&Source=SearchPage
```

- `City`: סמל יישוב של הלשכה המרכזית לסטטיסטיקה (סמל ישוב). `3000` = ירושלים. את
  האחרים יש לאתר ברשימת היישובים של הלמ"ס, או להשתמש בעמוד החיפוש של האתר עצמו ולקרוא
  את הקוד מהכתובת שמתקבלת.
- `PageNumber`: עמוד התוצאות, החל מ-1.
- `RequestId`: האתר מוסיף אותו בהפניה; יש להשמיט אותו.

**יש להשתמש בדפדפן.** שליפה פשוטה (fetch) החזירה עמוד חסימת בוטים עם HTTP 200
(2026-10-21), שנראה כמו תוצאה ריקה ואינו כזה.

## שלבים

1. יש לבנות את הכתובת ולפתוח אותה ב-Chrome.
2. יש לוודא שהעמוד מציג מרכזים רפואיים בעיר המבוקשת. אם לא:
   `CHANGED: branch results not found`.
3. יש לדווח שם, כתובת, טלפון ושעות פעילות היכן שהם מוצגים. יש לדפדף בעמודים כל עוד
   `PageNumber` מחזיר תוצאות.

מבנה עמוד התוצאות לא נותח ב-2026-10-21. יש לתאר את מה שרואים, ולהוסיף
את השדות לפרופיל בהרצה המוצלחת הראשונה.

## מקור

נצפה ב-2026-10-21 בסשן מחובר; נתיב `branch_finder` ב-`profiles/maccabi-online.json` (הסטטוס שם). עוגנים: תחביר הכתובת (דרגה 1), כותרת H1 וטקסט התוויות הגלוי (דרגה 4/6). אימות מחדש באמצעות `admin-rediscover-portal`.
